# 하준아~ 영어랑 놀자! — GitHub(화면) + 앱스스크립트(데이터·발음)

모바일 접속 문제를 없애기 위해 구조를 이렇게 나눴습니다.

```
GitHub Pages ── index.html (화면 전부)
     │  fetch (진도·발음만)
     ▼
Apps Script /exec ── 진도 저장/불러오기 + AI 발음(TTS)
```

- 화면을 GitHub가 띄우므로 **구글 로그인 쿠키에 의존하지 않습니다.**
  → 모바일 일반모드에서 안 열리던 문제가 사라집니다.

## ★ 하준이 진도는 그대로 보존됩니다

- 진도는 예전과 **똑같은 저장소**(스크립트 속성 `PHONICS_PROGRESS_V1`)에 있습니다.
  Code.gs 내용만 바꾸는 것이라 **레벨·별·아이템이 그 자리에 그대로** 있습니다.
- 앱도 안전장치가 있습니다:
  - 서버에서 진도를 정상적으로 불러오기 **전에는 서버에 저장하지 않습니다** (초기화 방지).
  - 서버 진도를 **빈 값으로 덮어쓰지 않습니다.** 서버·기기 중 더 진행된 쪽을 씁니다.
  - 만약을 위해 설정에 **💾 진도 백업/복원**도 있습니다.

## 1. 앱스스크립트 (Code.gs 교체)

1. **지금 쓰는 그 스크립트 프로젝트**에서 Code.gs 를 이 폴더의 Code.gs 로 교체
   (같은 프로젝트라야 진도가 유지됩니다. 새 프로젝트를 만들지 마세요.)
2. **배포 관리 > 기존 배포 편집 > 버전: 새 버전** 으로 올리기
   → 이렇게 하면 **/exec 주소가 그대로 유지**되고 진도도 그대로입니다.
3. Index.html 파일은 이제 앱스스크립트에 없어도 됩니다(지워도 되고 놔둬도 무방).

## 2. GitHub (index.html 교체)

1. 재이동(redirect)만 하던 index.html 을 이 폴더의 index.html 로 교체
2. Commit → GitHub Pages 자동 반영

index.html 맨 위 `GAS_URL` 에 현재 배포 주소가 이미 들어 있습니다.
주소가 바뀌면 그 한 줄만 고치면 됩니다.

## 3. 확인

GitHub 주소로 접속 → ⚙️ 설정 → 🩺 진단에서
**"서버 연결 (앱스스크립트 API) ✅ 정상"** 과 하준이 진도(별·레벨)가 보이면 성공입니다.

## 참고 — 크로스도메인 호출 방식
- 불러오기·AI상태·목소리(GET)는 **JSONP**(`?callback=`)로,
- 저장·초기화·발음합성(POST)은 **`Content-Type: text/plain`** 으로 호출합니다.
  둘 다 브라우저 프리플라이트 없이 GitHub ↔ 앱스스크립트 호출이 됩니다.
- 서버가 느리거나 막혀도 5초 뒤 **이 기기 저장(localStorage)** 으로 자동 전환되어 앱은 항상 열립니다.
